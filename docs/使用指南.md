# 天地熔炉 · 使用指南

> 私人 LoRA 训练工具：支持 SDXL（NoobAI / Illusion 等）与 DiT（Anima / Krea 2）。
> 双击 `start.bat` 即可一键点火，浏览器操作，全离线训练。

---

## 一、这是什么

天地熔炉把「模型 → 数据 → 训练 → 产物」全流程收敛成一个本地网页应用：

- **炼丹**：训练任务（炉火）的创建、监控、续练、取消
- **药材**：基底模型注册、训练数据集管理、自动打标、标签编辑
- **炉房**：镜像源等全局设置

架构：Rust 负责调度与界面（本仓库），Python 内核负责真正的训练计算
（sd-scripts 训 SDXL/Anima，ai-toolkit 训 Krea 2），内核装在独立虚拟环境里，
**不会污染系统 Python**。

---

## 二、仓库目录结构

| 路径 | 作用 |
|------|------|
| `start.bat` | **一键点火**：双击启动服务 + 自动打开浏览器（日常只用它） |
| `server_window.bat` | 服务窗口脚本（start.bat 内部调用，显示服务日志） |
| `crates/` | Rust 源码（10 个 crate，见下表） |
| `ui/` | 前端界面（React + Vite；`ui/dist` 是构建产物，由服务直接托管） |
| `docs/` | 架构设计、里程碑路线图、本指南 |
| `.kernel-ws/` | **实际工作区**：训练内核、模型、数据集、产物都在这（见第三节） |
| `测试底模/` | 你放的基底模型（anima / krea2 / NoobAI / Illusion 等） |
| `测试数据集/` | 你放的训练图片 + caption（`1_tag/` 子目录：图 + 同名 .txt） |
| `Cargo.toml` | Rust 工作区清单 |
| `.kernel-install/` | 内核安装中间产物（可忽略） |

### crates/ 下 10 个 Rust 模块

| crate | 职责 |
|-------|------|
| `tiandi-core` | 领域模型：任务状态机、事件总线（核心大脑） |
| `tiandi-state` | SQLite 存储：任务/指标/产物/设置等落库 |
| `tiandi-dataset` | 图像扫描、缩略图、dHash 去重、分辨率分桶 |
| `tiandi-recipe` | 丹方（训练参数配方）的 schema、校验、内置预设 |
| `tiandi-engine` | 训练引擎接口定义（Trainer trait） |
| `tiandi-engine-compat` | **内核桥**：Python 内核安装、TOML/YAML 参数生成、IPC 通信 |
| `tiandi-engine-native` | 远期原生训练内核（占位，未启用） |
| `tiandi-server` | 本地 HTTP 服务：API、SSE 事件流、任务队列调度 |
| `tiandi-cli` | 命令行：`tiandi init / doctor / kernel / models / server` |
| `tiandi-app` | Tauri 桌面壳（内嵌本地服务；日常用 start.bat 的浏览器模式即可） |

## 三、数据都在哪（.kernel-ws 工作区）

| 目录 | 存放内容 |
|------|----------|
| `.kernel/` | sd-scripts 训练内核：venv 虚拟环境 + sd-scripts 源码 + `kernel.json` 内核清单 |
| `.kernel-aitk/` | ai-toolkit 内核（Krea 2 用）：独立 venv + ai-toolkit 源码 |
| `models/` | 导入的底模 / VAE / 文本编码器（`models/base_model`、`models/vae`、`models/clip`）+ Krea 2 离线转换资产 |
| `datasets/` | （预留目录）数据集注册记录实际存于 `tiandi.db`，图片仍在你的目录里 |
| `runs/` | **每次训练的过程数据**：`runs/<任务ID>/` 下有配置、数据集镜像（`dataset/`）、日志、采样提示词 |
| `output/` | **训练产物**：`output/<任务ID>/checkpoints/` 下是每轮 LoRA 与断点状态（state），`output/<任务ID>/checkpoints/sample/` 是采样预览图 |
| `vault/` | （预留目录）药库备份区 |
| `tokenizers/` | 离线 tokenizer（CLIP-L/G，SDXL 用） |
| `tiandi.db` | 主数据库（SQLite：任务、指标、丹方、产物索引） |

> 提示：`output/` 里一个文件夹 = 一次炼丹；`checkpoints/*.safetensors` 就是炼出的 LoRA。

## 四、界面速览（左侧 3 个导航项）

### 丹方（默认页，LoRA 训练 / 全量训练）

- **表单即丹方**：左侧导航选「LoRA 训练」或「全量训练」，右侧是完整的训练参数表单，分 **9 个折叠分区**（训练用模型 / 数据集设置 / 网络设置 / 学习率与优化器 / 训练相关参数 / 精度与缓存 / 保存设置 / 预览图设置 / 质量技巧），默认展开前 3 区；每个参数带 `?` 悬停说明
- 全量微调模式自动隐藏 LoRA 专属分区（训练用模型 / 网络设置），并只保留「混合精度」一项缓存相关参数
- 底模与数据集通过**原生文件对话框**选择，随丹方一起保存，无需单独注册页面
- 保存丹方后可载入复用；点「点火炼丹」会先保存丹方再入队训练（名称留空时自动按底模文件名命名）
- 「训练文本编码器（TE）」开关：LoRA 训练通常保持关闭（更省显存）；开启时自动关闭「缓存文本编码器输出」；Anima 的 Qwen3 TE 需要时可开启
- 左侧「炼丹记录」：每次训练一条记录，显示状态（排队中/准备中/炼丹中/出炉/炸炉…），点击切换查看；失败原因直接显示在控制台日志流（红色行）

### 炼丹记录（训练控制台）

- **火候仪表盘**：训练进度环、loss / lr 曲线（SVG）
- **采样画廊 / 药库**：训练中生成的采样图（真实训练由内核落盘后自动上报）+ 训练完的 LoRA 产物（可重命名/删除）
- **日志流**：内核实时日志 + 失败原因（红色）
- **续丹（重试/断点续训）**：失败的任务一键重跑；训练中断过且有检查点时会从断点继续
- **熄灭（取消）**：取消排队/运行中的训练
- **顶部状态栏**：GPU 占用/显存实时显示 + 服务连接状态（断线自动重连并提示）

## 五、完整炼丹流程（从零到 LoRA，全程界面操作）

### 第 1 步：准备数据

把训练图片放进一个文件夹，每张图配一个**同名 .txt** 写描述（如 `01.png` + `01.txt`）。
两种目录结构都支持（选择"直接含图的文件夹"即可，无需手动建子目录）：
- 直接含图：`图片文件夹/01.png + 01.txt` —— 系统自动生成训练镜像 `runs/<任务ID>/dataset/<N>_data/`（硬链接，不复制原图）
- 子文件夹分组：`图片文件夹/10_cat/01.png`（`N_` 前缀 = 每张图训练 N 次；无前缀自动补 `1_`；横杠/空格分隔的前缀也会规范成 `N_名`；纯数字目录名按 1 次处理防误用）

### 第 2 步：创建丹方（丹方页）

1. 「丹方」页选择模型族（SDXL / Anima / Krea 2）
2. 点「选择底模」用原生对话框选 .safetensors（VAE/TE 按需选择；Anima/Krea 2 会自动探测同目录资产）
3. 点「选择数据集目录」选图片文件夹
4. 填写丹方名称与参数（不同模型族的要点见下表），点「保存丹方」；不填名称也可以直接「点火炼丹」，会自动按底模文件名命名

不同模型族的要点：

| 模型族 | 家族 | 关键差异 |
|--------|------|----------|
| NoobAI / Illusion | `sdxl1` | 勾选「缓存文本编码器输出」（快）；V 预测模型在预测类型选 `v` |
| Anima | `dit_anima` | 自动探测同目录 qwen3 + vae 并顺带导入；文本编码器缓存自动关闭（需训 Qwen3 TE） |
| Krea 2 | `dit_krea2` | flowmatch + linear；rank 建议 32；16GB 显存自动 qfloat8 + 低显存模式 |

> 全量微调目前走 sd-scripts 内核（SDXL / Anima 可用）；Krea 2 请用 LoRA 训练模式。

### 第 3 步：点火炼丹

1. 在丹方页点 **「点火炼丹」**（会先保存丹方再入队）
2. 任务列表里就能看到状态流转：排队中 → 准备中 → 炼丹中 → 出炉；右侧实时看 loss 曲线、采样图与日志（同一时间只跑一个任务）

### 第 4 步：收取产物

训练完成后，「炼丹记录」选中该任务 → 右侧「采样画廊 / 药库」里出现
`<丹方名>.safetensors`——就是你的 LoRA，可直接用于 ComfyUI / SD WebUI。
文件本体在 `.kernel-ws\output\<任务ID>\checkpoints\` 下。

失败的任务点 **续丹** 可重试（有检查点时会从断点继续）；**熄灭** 取消训练。
任务删除会同时清理其产物目录。

## 六、常用命令

```powershell
# 一键启动（日常）
start.bat                      # 或直接双击

# 命令行工具（在仓库根目录）
tiandi init                    # 初始化工作区
tiandi doctor                  # 环境体检（GPU/CUDA/磁盘/端口）
tiandi server --dir .kernel-ws --web   # 点火本地服务（浏览器模式，自动开浏览器）
tiandi kernel install          # 安装 sd-scripts 内核（首次，需联网）
tiandi kernel install-aitk     # 安装 ai-toolkit 内核（Krea 2，需联网）
tiandi kernel prepare-krea2 <模型目录>   # Krea 2 离线资产转换
tiandi models add --name X --family sdxl1 --path D:\...\x.safetensors
tiandi models list
```

## 七、常见问题

**Q：双击 start.bat 后浏览器打不开？**
手动访问 `http://127.0.0.1:18765`。若服务窗口报端口占用，服务会回退端口，UI 会自动探测 18765–18774。

**Q：任务一直「排队中」不开始？**
队列是串行的——同一时间只跑一个任务。确认没有其他任务在跑；失败的任务不会阻塞队列。

**Q：任务「炸炉」（失败）了怎么排查？**
选中任务 → 控制台日志流里红色行即为失败原因（如"内核启动失败"）；或看服务窗口日志。常见原因：模型路径不对、显存不足、内核未装。

**Q：训练很慢？**
Krea 2 是 120 亿参数模型，16GB 显存下 qfloat8 + 低显存模式每步约 2–4 分钟属正常。SDXL 系快得多（每步约 2 秒）。

**Q：想清空重来？**
删除 `.kernel-ws\runs\` 下对应任务文件夹（产物），或删 `tiandi.db` 重置全部记录（数据文件仍在）。

**Q：内核装坏了？**
删除 `.kernel-ws\.kernel\`（或 `.kernel-aitk\`）后重新 `tiandi kernel install`（install-aitk）。venv 与系统 Python 完全隔离，删了不污染系统。
