# 天地熔炉 · 使用指南

> 私人 LoRA 训练工具：支持 SDXL（NoobAI / Illusion 等）与 DiT（Anima / Krea 2）。
> 双击 `start.bat` 即可一键点火，浏览器操作，全离线训练。

---

## 一、这是什么

天地熔炉把「模型 → 数据 → 训练 → 产物」全流程收敛成一个本地网页应用：

- **炼丹**：训练任务（炉火）的创建、监控、续练、取消
- **药材**：基底模型注册、训练数据集管理、自动打标、标签编辑
- **炉房**：镜像源等全局设置

架构：Rust 负责调度与界面（本仓库），Python 内核负责真正的训练计算
（sd-scripts 训 SDXL/Anima，ai-toolkit 训 Krea 2），内核装在独立虚拟环境里，
**不会污染系统 Python**。

---

## 二、仓库目录结构

| 路径 | 作用 |
|------|------|
| `start.bat` | **一键点火**：双击启动服务 + 自动打开浏览器（日常只用它） |
| `server_window.bat` | 服务窗口脚本（start.bat 内部调用，显示服务日志） |
| `crates/` | Rust 源码（10 个 crate，见下表） |
| `ui/` | 前端界面（React + Vite；`ui/dist` 是构建产物，由服务直接托管） |
| `docs/` | 架构设计、里程碑路线图、本指南 |
| `.kernel-ws/` | **实际工作区**：训练内核、模型、数据集、产物都在这（见第三节） |
| `测试底模/` | 你放的基底模型（anima / krea2 / NoobAI / Illusion 等） |
| `测试数据集/` | 你放的训练图片 + caption（`1_tag/` 子目录：图 + 同名 .txt） |
| `Cargo.toml` | Rust 工作区清单 |
| `.kernel-install/` | 内核安装中间产物（可忽略） |

### crates/ 下 10 个 Rust 模块

| crate | 职责 |
|-------|------|
| `tiandi-core` | 领域模型：任务状态机、事件总线（核心大脑） |
| `tiandi-state` | SQLite 存储：任务/指标/产物/设置等落库 |
| `tiandi-dataset` | 图像扫描、缩略图、dHash 去重、分辨率分桶 |
| `tiandi-recipe` | 丹方（训练参数配方）的 schema、校验、内置预设 |
| `tiandi-engine` | 训练引擎接口定义（Trainer trait） |
| `tiandi-engine-compat` | **内核桥**：Python 内核安装、TOML/YAML 参数生成、IPC 通信 |
| `tiandi-engine-native` | 远期原生训练内核（占位，未启用） |
| `tiandi-server` | 本地 HTTP 服务：API、SSE 事件流、任务队列调度 |
| `tiandi-cli` | 命令行：`tiandi init / doctor / kernel / models / server` |
| `tiandi-app` | Tauri 桌面壳（占位，当前用浏览器模式） |

## 三、数据都在哪（.kernel-ws 工作区）

| 目录 | 存放内容 |
|------|----------|
| `.kernel/` | sd-scripts 训练内核：venv 虚拟环境 + sd-scripts 源码 + `kernel.json` 内核清单 |
| `.kernel-aitk/` | ai-toolkit 内核（Krea 2 用）：独立 venv + ai-toolkit 源码 |
| `models/` | Krea 2 离线转换资产（Qwen3-VL 文本编码器目录、VAE 目录） |
| `datasets/` | 在 UI 里注册的数据集记录（图片本身在你的目录里） |
| `runs/` | **每次训练的全部产出**：`runs/<任务ID>/` 下有配置、日志、checkpoints 产物、采样图 |
| `vault/` | 药库备份区（产物重命名/归档） |
| `tokenizers/` | 离线 tokenizer（CLIP-L/G，SDXL 用） |
| `tiandi.db` | 主数据库（SQLite：任务、指标、产物索引） |

> 提示：`runs/` 里一个文件夹 = 一次炼丹；`checkpoints/*.safetensors` 就是炼出的 LoRA。

## 四、界面速览（3 个页签）

### 炼丹（默认页）

- **左侧「炼丹任务」列表**：每次训练一条记录，显示状态（排队中/准备中/炼丹中/出炉/炸炉…），点击切换查看
- **「点火」按钮**：创建一条**模拟**训练（走完整链路演示，不需要真实内核）
- **右侧训练控制台**（选中任务后）：
  - 火候仪表盘：训练进度环、loss / lr 曲线（SVG）
  - 采样画廊 / 药库：训练中生成的采样图 + 训练完的 LoRA 产物（可重命名/删除）
  - 日志流：内核实时日志
  - **续丹（重试/断点续训）**：失败的任务一键重跑；训练中断过且有检查点时会从断点继续
  - **熄灭（取消）**：取消正在进行的训练
- **顶部状态栏**：GPU 占用/显存实时显示 + 服务连接状态

### 药材（数据准备）

- **基底模型**：训练底模注册（名称 + 模型族 + safetensors 路径）。家族：`sdxl1`（NoobAI/Illusion）、`dit_anima`、`dit_krea2`
- **数据集**：注册数据集（填图片文件夹路径）→ **扫描（导入/去重/分桶）** → 打标
  - 扫描：生成缩略图、检测重复图、按分辨率分桶
  - 打标（mock）：占位标签（演示）；打标（WD14）：真实自动打标（需内核环境，当前未装 WD14 模型）
- **标签编辑器**：图片网格 + 标签云 + 选中图片后手动改 caption（批量替换字符串/正则）

### 炉房（设置）

- 镜像源：HF 镜像（`hf-mirror.com`）与 pip 镜像——注入训练内核，大陆网络加速

## 五、完整炼丹流程（从零到 LoRA）

> ⚠️ **现状说明**：丹方（训练参数）与**真实任务创建**目前还没有界面按钮，
> 需要复制下面的命令执行（在 `D:\Projects\tiandi` 打开终端）。UI 补全这两块正在规划。

### 第 1 步：准备数据

把训练图片放进一个文件夹，每张图配一个**同名 .txt** 写描述（如 `01.png` + `01.txt`）。
然后在「药材」页注册数据集 → 点「扫描」。

### 第 2 步：注册基底模型

「药材」页 → 基底模型 → 填名称、选家族、填模型文件路径 → 注册。
（或者命令行：`tiandi models add --name NoobAI --family sdxl1 --path D:\...\noobai.safetensors`）

### 第 3 步：创建丹方（命令）

丹方 = 训练参数配方。在仓库根目录执行（示例：NoobAI/SDXL 冒烟配置）：

```powershell
# 查看内置预设（也可让 AI 帮你生成）
curl.exe http://127.0.0.1:18765/api/recipes/presets

# 创建丹方（POST /api/recipes，data 里是完整参数）
$data = @{
  learning_rate = 0.0001; optimizer = 'adamw8bit'; lr_scheduler = 'cosine'
  network_dim = 16; network_alpha = 16; network_type = 'lora'
  max_train_epochs = 10; batch_size = 1; resolution = 1024
  cache_latents = $true; cache_text_encoder_outputs = $true
  mixed_precision = 'bf16'; gradient_checkpointing = $true
  trigger_word = 'your_trigger'; shuffle_caption = $true
  save_every_n_epochs = 1
}
$body = @{ name = '我的丹方'; family = 'sdxl1'; data = $data } | ConvertTo-Json -Depth 5
curl.exe -X POST http://127.0.0.1:18765/api/recipes -H "Content-Type: application/json" -d $body
```

不同模型族的要点：

| 模型族 | family | 关键差异 |
|--------|--------|----------|
| NoobAI / Illusion | `sdxl1` | `cache_text_encoder_outputs=true`（快）；V 预测模型加 `prediction_type='v'` |
| Anima | `dit_anima` | 自动探测同目录 qwen3 + vae；`cache_text_encoder_outputs` 强制 false（需训 Qwen3 TE） |
| Krea 2 | `dit_krea2` | flowmatch + linear；rank 建议 32；16GB 显存自动 qfloat8 + 低显存模式 |

### 第 4 步：创建并启动训练任务（命令）

```powershell
# 需要 数据集ID、丹方ID、模型ID（从 UI 或 GET /api/datasets、/api/recipes、/api/models 查询）
$body = @{ dataset_id = '<数据集ID>'; recipe_id = '<丹方ID>'; base_model_id = '<模型ID>' } | ConvertTo-Json
$r = curl.exe -s -X POST http://127.0.0.1:18765/api/runs -H "Content-Type: application/json" -d $body
# 入队（scheduler 自动串行拉起）
curl.exe -s -X POST "http://127.0.0.1:18765/api/runs/<任务ID>/start"
```

然后回到「炼丹」页即可看到任务进入排队 → 准备 → 炼丹，实时看 loss 曲线与日志。

### 第 5 步：收取产物

训练完成后，「炼丹」页选中该任务 → 右侧「采样画廊 / 药库」里出现
`<丹方名>.safetensors`——就是你的 LoRA，可直接用于 ComfyUI / SD WebUI。
文件本体在 `.kernel-ws\runs\<任务ID>\checkpoints\` 下。

## 六、常用命令

```powershell
# 一键启动（日常）
start.bat                      # 或直接双击

# 命令行工具（在仓库根目录）
tiandi init                    # 初始化工作区
tiandi doctor                  # 环境体检（GPU/CUDA/磁盘/端口）
tiandi kernel install          # 安装 sd-scripts 内核（首次，需联网）
tiandi kernel install-aitk     # 安装 ai-toolkit 内核（Krea 2，需联网）
tiandi kernel prepare-krea2 <模型目录>   # Krea 2 离线资产转换
tiandi models add --name X --family sdxl1 --path D:\...\x.safetensors
tiandi models list
```

## 七、常见问题

**Q：双击 start.bat 后浏览器打不开？**
手动访问 `http://127.0.0.1:18765`。若服务窗口报端口占用，服务会回退端口，UI 会自动探测 18765–18774。

**Q：任务一直「排队中」不开始？**
队列是串行的——同一时间只跑一个任务。确认没有其他任务在跑；失败的任务不会阻塞队列。

**Q：任务「炸炉」（失败）了怎么排查？**
选中任务 → 日志流看尾部报错；或看服务窗口日志。常见原因：模型路径不对、显存不足、内核未装。

**Q：训练很慢？**
Krea 2 是 120 亿参数模型，16GB 显存下 qfloat8 + 低显存模式每步约 2–4 分钟属正常。SDXL 系快得多（每步约 2 秒）。

**Q：想清空重来？**
删除 `.kernel-ws\runs\` 下对应任务文件夹（产物），或删 `tiandi.db` 重置全部记录（数据文件仍在）。

**Q：内核装坏了？**
删除 `.kernel-ws\.kernel\`（或 `.kernel-aitk\`）后重新 `tiandi kernel install`（install-aitk）。venv 与系统 Python 完全隔离，删了不污染系统。
